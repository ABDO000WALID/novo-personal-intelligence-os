# NOVO - Personal Intelligence OS 🧠🚀

NOVO is an advanced, web-based personal AI assistant and workspace application designed to streamline daily tasks, manage state seamlessly, and provide a highly reliable AI chat experience.

## 🌟 Key Features

* **Advanced AI Orchestrator:** Intelligent chat system with dynamic model failover to ensure zero downtime and continuous reliability.
* **Real-Time State Synchronization:** Seamless data flow between the frontend state manager and the backend database.
* **Modern UI/UX:** Clean, responsive, and highly interactive user interface.
* **Secure & Scalable:** Built with robust authentication and structured database rules.

## 🛠️ Tech Stack

* **Frontend:** React, Vite, TypeScript, Tailwind CSS
* **State Management:** Zustand
* **Backend & Database:** Node.js, Express, Firebase (Firestore & Auth)
* **AI Integration:** Custom Orchestrator with Multi-Model Failover Support
